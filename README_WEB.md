# 中文小说生成器 Web 界面

## 🎯 项目简介

这是一个基于 Flask + Socket.IO 的中文小说生成器 Web 应用，提供类似 Trae IDE 的现代化界面设计。用户可以通过右侧聊天界面与AI交互，在中间区域实时查看生成的小说内容。

## ✨ 主要特性

- **🎨 现代化界面设计**：类似 Trae 的三栏布局（左侧导航、中间内容、右侧聊天）
- **💬 实时聊天交互**：通过 Socket.IO 实现实时通信
- **📖 流式内容展示**：小说内容逐章节实时显示
- **📱 响应式设计**：支持不同屏幕尺寸
- **💾 本地存储**：支持保存和管理最近生成的小说
- **🎯 智能提示**：提供示例提示词帮助用户快速开始

## 🏗️ 技术架构

### 前端技术栈
- **HTML5**：语义化结构
- **CSS3**：现代化样式，渐变背景，动画效果
- **JavaScript (ES6+)**：交互逻辑和实时通信
- **Socket.IO Client**：WebSocket 通信
- **Font Awesome**：图标库
- **Google Fonts**：Inter 字体

### 后端技术栈
- **Flask**：Web 框架
- **Flask-SocketIO**：WebSocket 支持
- **Python Threading**：异步任务处理
- **Moyun 故事生成引擎**：AI 小说生成核心

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python web/web_app.py
```

### 3. 访问界面

- 本地访问：http://localhost:5000
- 局域网访问：http://[你的IP]:5000

## 🎮 使用指南

### 基本操作

1. **发送消息**：在右侧聊天框输入您想要的小说内容描述
2. **快速开始**：点击示例提示词快速体验
3. **查看内容**：生成的小说会在中间区域实时显示
4. **保存小说**：点击"保存"按钮下载小说文件
5. **清空内容**：点击"清空"按钮重新开始

### 示例提示词

- "写一个青春校园爱情故事"
- "创作一个科幻冒险小说"
- "写一个古代武侠传奇"

### 快捷键

- **Ctrl + Enter**：发送消息
- **Enter**：发送消息（可选）

## 🔍 故障排除

### 常见问题

1. **应用无法启动**
   - 检查依赖是否安装完整
   - 确认端口 5000 未被占用

2. **AI 生成失败**
   - 检查 ENDPOINT 环境变量配置
   - 确认后端 AI 服务正常运行

3. **界面显示异常**
   - 清除浏览器缓存
   - 检查静态文件路径

### 调试模式

应用默认开启调试模式，可以在控制台查看详细日志：

```bash

INFO:werkzeug:127.0.0.1 - - [时间] "GET / HTTP/1.1" 200
```
